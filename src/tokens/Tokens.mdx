# Tokens

Two layers. **Components only use semantic tokens**; semantic tokens point at primitives

## Semantic

{Object.entries(tokens.semantic).map(([k, v]) => <Swatch key={k} name={k} value={'→ ' + v.replace(/[{}]/g, '')} cssVar={'--' + k.replace(/\//g, '-')} />)}

## Colour primitives

{Object.entries(tokens.primitives.color).map(([k, v]) => <Swatch key={k} name={'color/' + k} value={v} cssVar={'--color-' + k} />)}

## Spacing and radius

Every padding, gap and radius sits on a 4 px grid
