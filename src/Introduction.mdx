## <T en="How it’s built" ru="Как устроено" />

<T
  en={<ul>
    <li><strong>Tokens in two layers.</strong> Primitives hold raw values; components use only semantic tokens (<code>button/primary/bg</code>, <code>text/secondary</code>), so a brand or a theme changes in one place. <code>tokens.json</code> is the source of truth, <code>npm run tokens</code> generates the CSS variables</li>
    <li><strong>Components</strong> – Button, Bottom sheet, Full screen message, List item. Every prop maps to a component property in Figma</li>
    <li><strong>Accessibility</strong> is tested on every story with axe – a violation fails the build. The first run caught what Figma didn’t show: secondary button text at 3.98:1 contrast (now 5.3:1) and loading buttons losing their name</li>
    <li><strong>Localisation</strong> – the same components in English and Russian, including labels screen readers hear</li>
    <li><strong>Readable by AI agents</strong> – the Storybook MCP addon exposes components and their docs to coding agents</li>
  </ul>}
  ru={<ul>
    <li><strong>Токены в два слоя.</strong> Примитивы хранят значения; компоненты используют только семантические токены (<code>button/primary/bg</code>, <code>text/secondary</code>), поэтому бренд или тема меняются в одном месте. <code>tokens.json</code> – источник правды, <code>npm run tokens</code> собирает CSS-переменные</li>
    <li><strong>Компоненты</strong> – Button, Bottom sheet, Full screen message, List item. Каждое свойство соответствует свойству компонента в Figma</li>
    <li><strong>Доступность</strong> проверяется на каждой истории через axe – нарушение роняет сборку. Первый же прогон нашёл то, чего не видно в Figma: контраст текста вторичной кнопки 3,98:1 (теперь 5,3:1) и потерю названия у кнопки при загрузке</li>
    <li><strong>Локализация</strong> – те же компоненты на английском и русском, включая подписи для скринридеров</li>
    <li><strong>Понятно ИИ-агентам</strong> – аддон Storybook MCP открывает компоненты и документацию агентам, которые пишут код</li>
  </ul>}
